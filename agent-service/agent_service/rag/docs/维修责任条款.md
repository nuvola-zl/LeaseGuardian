# 维修责任条款

## 人为损坏责任
人为损坏由租客承担维修费用。因使用不当、疏忽或故意造成的损坏，租客需承担维修或赔偿费用。

## 自然老化责任
自然老化由房东承担维修费用。正常使用导致的部件老化、损耗，由房东负责维修更换。

## 维修响应时限
一般维修24小时内响应，紧急维修（漏水、漏电、燃气等）2小时内响应，节假日照常受理。

## 紧急维修处理
漏水严重、漏电、燃气泄漏等紧急情况，租客应立即采取止损措施（关闭总阀、断开电源、开窗通风），并第一时间联系楼栋管理员。

## 费用争议处理
维修完成后，按实际责任方结算费用；如有争议，以入住登记和维修记录为依据。

## 维修配合义务
维修期间租客应配合师傅入户，家中贵重物品请提前妥善保管；因无法入户导致的延误由租客承担。
