## CLAUSE-DEPOSIT 押金退还
租赁合同期满或退租完成，押金在扣除水电欠费、已核定损坏赔偿后退还剩余部分；退租确认后 1-3 个工作日内到账（演示数据）。

## CLAUSE-UNUSED-RENT 剩余整月租金
退租时，搬离当月与到期当月不计，中间夹着的整自然月按整月租金退还。剩余整月数 = max(0, 到期年月 - 搬离年月 - 1)。搬离日等于到期日则剩余为 0，只退押金。

## CLAUSE-DAMAGE 损坏责任与赔偿
租客人为损坏应承担赔偿责任；自然老化不属于租客赔偿范围。损坏赔偿金额以核定为准，存在争议时转人工核定，AI 不拍板最终金额。

## CLAUSE-UTILITY 水电结算
退租结算时，未结清的水电账单作为欠费从应退金额中扣减；扣减项须能对应账单或合同条款依据。

## CLAUSE-EXPIRED 到期未退
租约到期且租客未发起退租的，租约自动视为 EXPIRED；已到期合同无需再走退租流程。

## CLAUSE-CANCEL 免费取消
租客在确认退租前可免费反悔取消；取消后租约恢复生效，不产生任何费用。
